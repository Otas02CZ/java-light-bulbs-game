## Basic Information
This game is a Light Bulbs clone. Player rotates wire, power and bulb cells so that all bulbs
are powered on.

## Implementation Notes
The game supports random generation of game map that is configurable by its size, coefficient of empty cells and shuffling strength.
Saving and loading is supported as well and the save files are common JSON files.

## Building and Running
Command `mvn package` builds and packs the game into a `.jar` archive `lightbulbgame.jar` located in folder `target`.
This jar archive contains compiled application classes as well as all dependencies and libraries. All assets like fonts, icons and
backgrounds are included as well. So the application can be simply run with command `java -jar target/lightbulbgame.jar`
This can be simplified with the use of supplied Makefile by running `make try`.

The produced archive should contain all necessary dependencies required by the program to run on all platforms (linux, win, mac).
This is done by including native libraries for javafx graphics for all platforms. Even though everything should be included
we encountered some issues with running archives created on windows on mac.

## Generating Documentation
Documentation can be generated by running command `mvn javadoc:javadoc` or `make docs` and is placed in folder `docs`.

## Project Structure
All Java source files as well as game assets (fonts, icons, backgrounds, ...) are located in the `src` directory. Assets are
specifically contained in subfolder `src/main/resources`. This structure of the project assures that game assets are automatically
added to the resulting archive by maven. Configuration in `pom.xml` also forces maven to store all required libraries (even native)
in the archive as well. Due to this structuring of the project we do not use the folder `lib` and it remains empty.

Folder `data` contains example save files.
